Self-tests
The pure logic this app relies on: URL cleaning and the rule engine, the Netscape reader and writer, the title-cleanup rules and the three URL keys. No library is needed, nothing is changed, and the same suite runs standalone in self-test.html.

Run the tests to see every check.

Results and reports
JSON compares, folder rankings and domain health render here so nothing has to fall back to a pop-up.

Compare a JSON file (Import and Backup → Compare), or run one of the reports on the Statistics tab.

Validate library
Structural problems the other scans do not cover: bookmarks with no title, bookmarks whose URL is not a page (javascript:, data:, about:), sibling folders sharing a name, and folders whose date is older than their own newest child. Fixes are previewed and applied as one undo step.

Scan to check the library's structure.

Never opened
Bookmarks the browser has no recorded use for, or whose last use is older than the cut-off. Firefox only reports a last-used date for some bookmarks, so “never recorded” is a hint rather than proof; the delete preview still honours protected folders.

Scan to list bookmarks with no recorded use.

Bookmark notes
Notes are kept by the app in this browser and keyed by URL: Firefox's API cannot store descriptions. Editing a URL moves its note along. This scan finds notes whose bookmark is gone.

Scan to list stored notes that no longer match a bookmark.

Duplicate Links (Same ID)

Click scan to find duplicates. Every copy except the oldest is checked; Delete removes the checked copies.

Normalize & deduplicate YouTube
Converts eligible YouTube video bookmarks to https://www.youtube.com/watch?v=VIDEO_ID, then removes duplicates by video ID. Shorts are left unchanged. The bookmark with the oldest dateAdded is retained; the title comparison ignores a trailing - YouTube. Scan first, then apply.
Unsame Titles (Same ID, Different Bookmark Title)

Find bookmarks that point to the same video but have differing titles.

Missing " - YouTube" Suffix
Automatically appends " - YouTube" to video bookmarks that don't end with it. Scan first, then apply.
Malformed watch-page titles

Finds titles scraped from the YouTube watch UI: duration, mashed channel, view count, “ago”, Live, Playlist (), Mix (50+), then - YouTube. Edit the cleaned title in the table before Clean.

Hacker News Tools

Affected patterns: hcker.news/?comments=
Convert to Native YCombinator URLs
Transforms URLs to news.ycombinator.com/item?id=... and cleans titles. Scan first, then apply.

Reddit Tools

Files bookmarks sitting in a Reddit Links folder into child folders named after the subreddit only (news, programming — no slash). Subreddit is read from /r/name in the URL, or from a title like Post title : news.
Sort Reddit Links into subreddit folders
Only moves items that are not already in a matching subreddit folder (legacy r/… names still count as already filed). Creates missing folders under Reddit Links. Items without a detectable subreddit are left in place.

Scan to preview how many bookmarks would move.

Sort Reddit Links into subreddit folders v2 (experimental)
Reads top-level Bookmarks Toolbar folders named description - sub1 sub2 …. Each space-separated name is a subreddit. First files loose matching bookmarks under Other Bookmarks → Reddit Links into a subreddit-named folder there (creates the folder only if missing). Then nests that original subreddit folder under the matching toolbar group (a folder move, so it leaves Reddit Links). Bookmarks stay inside the subreddit folder — they are not flattened into the group. If the group already has that folder, bookmarks are merged into it and the empty source is removed only after. Finally sorts leftover folders under Reddit Links A→Z (case-insensitive); remaining loose links keep their order after the folders. Unlisted subreddits stay in Reddit Links. If a name appears in two categories, the first toolbar folder wins.

Scan v2 to preview toolbar categories and Reddit Links moves.

Same post, different comment chains
Finds Reddit bookmarks that share a post id but different comment permalinks. Apply keeps the oldest (post-only wins ties) and removes the extras.

Scan to list posts that have more than one comment chain.

Meta Tools

Affected patterns: facebook.com, m.facebook.com, fb.com, fb.watch, instagram.com, instagr.am.
Notification count in title
Strips a leading unread-count prefix from Facebook and Instagram bookmark titles. Examples: (20+) Video | Facebook → Video | Facebook, (14) Entrepreneurs for Nepal | Facebook → Entrepreneurs for Nepal | Facebook, (3) Instagram → Instagram. Scan first, then apply.

General repairs

Fixes import damage in a bookmark JSON file: Unix-second dateAdded (Firefox shows 12/31/69), broken titles/URLs, short links, tracking params, and folder merges. Scan first, then apply. Export JSON to keep the result.
Replace Unix-second dateAdded with lastModified
Treats missing, zero, NaN, Netscape Unix-second ADD_DATE (raw value < 1e11, e.g. 2011000000), and dates before 2 Jan 1970 as broken. Repair copies a valid lastModified onto dateAdded (does not keep the Unix-second wall-clock). If lastModified is missing or also malformed, copies dateLastUsed when valid, otherwise sets now.

Scan to preview dateAdded before and after.

Short-link expander (offline)
Rewrites youtu.be, YouTube embed/mobile, redd.it, and *.m.wikipedia.org to canonical hosts with no network. t.co and amzn.to cannot be expanded offline and are listed only.

Scan to preview each URL before and after.

Tracking-parameter stripper
Drops utm_*, fbclid, gclid, YouTube si=, and similar trackers. Scan lists every parameter that would be removed.

Scan to preview each URL and the parameters that would be stripped.

Title cleanup
Site suffixes are stripped only when the text after the separator names that link's own host or parent domain; whitespace collapses and edge separators come off; ALL CAPS longer than 12 characters folds to sentence case; emoji runs come off only at the very start or end, never down to an empty title.

Scan to preview each title before and after.

Broken links by domain
Groups the broken title/URL scan and the dead rows of a finished Link check by parent domain. One checkbox per broken link plus an “all N” toggle per domain; a link that was never checked is never counted. Delete opens the shared delete preview, so protected folders are honoured.

Scan to group broken links by domain.

Find and replace
A regular expression over titles, URLs, or both, in the selection, the open folder, or the whole library. Scan previews every before/after pair; Replace applies to the checked rows as one undoable step.

Scan to preview every entry the pattern matches.

Bulk edit titles
Rebuild titles from a template instead of a find-and-replace. Tokens: {title} {url} {domain} {folder} {date} {n} (1, 2, 3…) and {nn} (01, 02…). Previewed, then applied as one undo step.

Scan to preview every title the template would change.

Same title and domain
Finds bookmarks whose title and parent domain match but whose URLs differ, which catches the same page saved with different tracking parameters or query strings. The first copy of each group is kept; check the extras to delete them.

Scan to group bookmarks that look like the same page.

Library health
Every scan in one table with its count, so you can see what needs attention and jump straight to it. Fix safe ones strips tracking parameters and removes empty folders in one undoable step; everything else stays manual.

Scan to count what is wrong across the library.

Merge duplicate sibling folders
Merges two folders with the same name under one parent (including news vs r/news). Children move into the older folder. Scan first, then apply.

Scan to preview which folder is kept and which is merged away.

Same path, different query
Groups bookmarks by host + path (AMP segments ignored). If the query strings differ, keeps the oldest and removes the rest.

Scan to preview each extra bookmark and the URL that would be kept.

AMP paths and old.reddit.com
Strips /amp from paths and rewrites old.reddit.com / m.reddit.com / np.reddit.com to www.reddit.com.

Scan to preview each URL before and after.

HTML-entity titles
Decodes &amp;, &quot;, and numeric entities in titles.

Scan to preview each title before and after.

Broken titles, URLs, and unparseable links
Lists bookmarks whose title or URL contains broken, empty hrefs, and values that fail new URL(). Bookmark rows are checked; Delete removes the checked ones. Folders are listed only; edit them from the Bookmarks tab.

Scan to list broken titles and URLs.

Duplicates

Groups bookmarks that share a URL. Mark copies, then remove the selection. The folder path opens that folder in Bookmarks. The eye shows that bookmark; the folder mark/unmark button selects every duplicate in that folder across all groups. The trash on a URL group marks every copy except the oldest. Select newest in same folder checks only the newer copy when two or more copies of a URL sit in one folder, and leaves the oldest unchecked. Select outer nested copies checks a copy when the same URL is also saved somewhere inside one of that folder’s subfolders, so only the most deeply nested copy stays unchecked. Use Remove all selected to delete what is checked (disabled until at least one copy is checked).

Find duplicate bookmarks to list groups.

Nearby Bookmarks

100 bookmarks before and 100 after the chosen bookmark, ordered by dateAdded. Search bookmarks are marked so a gap in a search chain is easier to see.

Right-click a bookmark and choose Nearby bookmarks.

Link check

Fetches each http(s) bookmark (6 at a time, 12s timeout). Live add-on only. Scope:
Dead links
Dead means 404/410, no response, or timed out. Other HTTP errors are listed unchecked.

Check to list dead links.

URL-only titles
Bookmarks whose title is empty or the URL get the page’s <title> (YouTube via oEmbed).

Fetch titles to preview each rename.

Script Lab

Run a custom JavaScript transformation against the loaded bookmark tree.
Custom bookmark script

Your script receives bookmarks (the full root object) and api. Use api.walk((node, parent) => { ... }) to visit each item, api.log(type, title, details) for the affected log, and api.selectedFolder() for the current folder. Changes remain unsaved until you export.
